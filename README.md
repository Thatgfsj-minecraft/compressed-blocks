# Compressed Blocks（压缩方块）

把常见方块 3×3 压缩成 1~9 重，方便携带；压缩方块和压缩木棍可以做成工具，**耐久按 9ⁿ 指数上升、挖掘速度逐重提升，六重及以上直接不可破坏**。0.3.0 新增压缩护甲、农业系统（压缩耕地/作物/树苗/树叶）与压缩食物。

Thatgfsj-minecraft 组织出品，开发约定见 [mc-mod-dev-skill](https://github.com/Thatgfsj-minecraft/mc-mod-dev-skill)。

## 特性

- **387 种压缩储存方块**（43 材料 × 1~9 重）：
  - 石族：圆石、石头、深板岩圆石、深板岩
  - 原木：橡木/云杉/白桦/丛林/金合欢/深色橡木/红树/樱花/苍白橡木
  - 常见：泥土、沙子、沙砾、下界岩、末地石、黑曜石
  - 0.3.0 新建材 24 种：花岗岩/闪长岩/安山岩/方解石/凝灰岩/砂岩/红砂岩/玄武岩/黑石/钟乳石/陶瓦/石英块/紫珀块/海晶石/紫水晶块/荧石（发光 15）/黏土块/干草块/骨块/苔藓块/雪块/冰/浮冰/泥巴
  - **硬度 = 50×1.2^(重-1)**（黑曜石级起步，逐重更难挖），**全部 1200 爆炸抗性（炸不毁）**
- **9 重压缩木棍**：9 木棍 → 压缩木棍 → 二重压缩木棍 → …
- **90 件压缩工具（两条线）**：压缩圆石工具（圆石+深板岩圆石可混用）、压缩木质工具（9 种原木可混用）× 镐/斧/锹/锄/剑 × 9 重
  - **耐久 = 9ⁿ × 基础**（石 131 / 木 59）；**六重起不可破坏**
  - **挖掘速度逐级连乘 ×1.5**：一重 6.0（铁镐）、二重 8.0（钻镐）、三重 12.0（金镐）、四重 18 → 九重 136.7；剑不参与（保持原版）
  - **攻击伤害 = 原版 + 重数**；挖掘等级阶梯：7 重=铁、8 重=钻石、9 重=下界合金，**九重工具可挖基岩且基岩会掉落**
  - 附魔能力 = 原版石级/木级；铁砧修复 = 同重数的混用组（圆石线=圆石+深板岩圆石，木线=任一原木）
- **36 件压缩护甲**（石头制 × 4 件 × 9 重）
  - 基准铁级（头 2/胸 6/腿 5/靴 2），每重每件 +1，**单件封顶 10，超出部分转抗性提升**（等级=穿戴件溢出总和）
  - 耐久 = 9ⁿ × 铁甲基准，六重起不可破坏；附魔能力 9，修复材料 = 同重数压缩石头
  - **四件全九重 = 免疫一切伤害（含 /kill、虚空）+ 饱食度/饱和度常满**
- **农业系统**
  - **压缩耕地**（9 级）：锄 N 级压缩泥土需要 **N 级或以上**压缩锄头；无踩踏退化；挖掉掉回同重数压缩泥土
  - **压缩作物**（小麦/胡萝卜/马铃薯/甜菜根 × 3 级）：只能种在**等级足够**的压缩耕地上，种错会有彩色英文提示
  - 压缩小麦不可合成，只能靠**压缩种子**种出来（收获=压缩小麦+压缩种子，出货量结构同原版）；9 干草块 = 二重压缩小麦（原版 9 麦=干草块）；西瓜同理走西瓜块
  - **压缩树苗**（9 树种 × 9 重）：种在等级足够的压缩泥土上；**树形与原版一致**（含巨型云杉/巨型丛林/深色橡木 2×2 规则），树干树叶 = 同重数压缩方块；压缩树叶走原版凋落算法，掉落 5%+时运的压缩树苗
- **压缩食物**（压缩面包/压缩牛肉/压缩西瓜 × 3 级）
  - 数值 = 原版 × 9^重；canAlwaysEat（饱了也能吃，金苹果式）
  - **营养溢出 → 主动回血**：溢出≤200 回升1×溢出秒；>200 回升2×(溢出-200)秒；>1000 回升5×(溢出/2)秒，无上限
- 合成：3×3 压缩（9→1）、无序解压（1→9）、工具/盔甲按原版排列
- 创造物品栏：四个分类栏（压缩方块 / 压缩工具 / 压缩食物 / 压缩盆栽）
- **压缩盆栽**（普通/漏斗盆栽，Botany Pots 机制）：盆内右键填压缩泥土/沙子 → 种压缩作物/树苗/任意材料甘蔗（重数 ≤ 土壤重数）→ 盆内渲染随生长从 20% 缩放到 50% → 60 秒一茬 → 右键收割**自动补种**（作物走原版战利品表含时运；树苗=同重数原木 4-6+树苗；甘蔗=2-4×自身）。漏斗盆栽成熟自动收割并优先塞进下方容器，全自动化
- **压缩甘蔗全材料化**：51 种储存材料各一条甘蔗线（钻石/煤炭/铁/火药/骨块……）+ 纯甘蔗，1x = 8 甘蔗 + 1 同级压缩方块居中，之后 9 个升级、分解返同级压缩方块；只能种在 N 重以上压缩泥土/沙子，生长同原版
- **盔甲分部位效果**（不注入任何附魔，不干扰原版附魔；**6 重及以下无任何效果**，7 重起步）：头盔 7 重=夜视（20 秒防闪烁）、8 重=+水下呼吸；护腿 7/8/9 重=抗性 1/2/3、9 重=+急迫 2；胸甲 8 重=飞行（疾跑=鞘翅速度）；靴子无效果；不死+饱食常满仅九重石甲满套；木质盔甲效果自动降一档

## 构建 / 测试

```bash
cd 1.21.11/fabric   && GRADLE_USER_HOME=<干净目录> ./gradlew build
cd 1.21.11/neoforge && GRADLE_USER_HOME=<干净目录> ./gradlew build
# 产物：build/libs/compressedblocks-<loader>-<mc版本>-<version>.jar
```

- 环境：Loom 1.17.21 / ModDevGradle 2.0.147 / Gradle 9.5.1 / JDK 21（版本坐标在各子项目 gradle.properties）
- **GRADLE_USER_HOME 必须指向无 init.gradle 的干净目录**（全局阿里云镜像会破坏 NeoForge 解析）
- 贴图与全部 JSON 由脚本生成：`python scripts/gen_assets.py && python scripts/gen_resources.py`（原版 sprite 缓存于 `_asset-src/vanilla/`，树特征模板在 `_asset-src/vanilla-data/`，均不入库）
- E2E：`ci/` 下的专用服 + RCON 断言（`node ci/e2e.js`，环境变量 `RCON_PORT` 指定端口），服务器启动日志搜 `SELF-TEST PASS`（服务端权威比对注册数/硬度公式/护甲属性/食物数值/标签族）

## 素材说明

全部贴图由 `scripts/gen_assets.py` 从**原版** sprite 程序化重绘，未复制任何第三方模组像素。压缩层视觉语言：底图灰色滤镜 + 外围压缩环封顶 5 圈（1~5 重黑/浅黑圈；6~8 重外围改深紫/浅紫圈；9 重最外圈白色细圈）；物品按同一配色逐级染色；盔甲 = 铁甲图层重着色为石质。
